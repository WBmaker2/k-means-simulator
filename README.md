# K-means 우리 동네 시설 위치 찾기

초등학생이 K-means 알고리즘을 단계별로 관찰하고 K=2~6 결과를 비교해 보는 학습 도구입니다.

## 실행

브라우저에서 [index.html](index.html)을 열거나 GitHub Pages의 [시뮬레이터](https://wbmaker2.github.io/k-means-simulator/)에 접속하세요.

외부 CDN, 외부 폰트, 외부 아이콘 없이 `assets/`의 로컬 CSS와 SVG 아이콘을 사용하므로 네트워크가 제한된 환경에서도 기본 화면이 유지됩니다.

## 포함 내용

- 단계별 K-means 시뮬레이션
- K=2~6 선택과 결과 비교
- 공공자전거·무더위 쉼터·무인 회수기 주제 전환
- 엔트리(Entry) 연계 활동지와 CSV 예시 데이터
- 교사용 10분 수업안과 디자인 QA 기록

## 파일 안내

- `index.html`: 메인 시뮬레이터
- `assets/kmeans-simulator.css`: 오프라인용 디자인 시스템
- `assets/kmeans-icons.js`: 로컬 SVG 아이콘 렌더러
- `K-평균-수업-활동지.html`: 인쇄용 활동지
